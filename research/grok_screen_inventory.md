# Grok Android App — Screen Inventory & Navigation Topology

**Target App:** `ai.x.grok.bot` (`SandMobile` v1.15.0 / build 1033)  
**Target Hardware:** Samsung Galaxy A07 (`SM-A075F`, Android 16 / API 36)  
**Evidence Basis:** `assets/app.config`, `assets/app.manifest`, Hermes Bytecode Route Registry (`assets/index.android.bundle`), Decoded `AndroidManifest.xml`, and Live Hardware Verification.

## 2. Navigation Flow & User Journey Architecture

```mermaid
flowchart TD
    subgraph Onboarding ["First Use & Authentication"]
        A["App Launch"] --> B["Onboarding Screen (#141414)<br/>Floating Avatars + 'Log In or Sign Up'"]
        B -->|Tap Login| C["Auth Sheet / OAuth<br/>Google / X / Email / Passkey"]
        C -->|Authenticated| D["Main Agent Workspace"]
    end

    subgraph PrimaryWorkspace ["Primary Chat & Agent Workspace"]
        D --> E["Chat Screen (/chat/[agentId])"]
        E -->|Swipe Row Left| F["Quick Action Tray<br/>Fork / Copy / Raw JSON"]
        E -->|Tap Tool Badge| G["Tool Execution Detail / Approval Sheet"]
        E -->|Tap Terminal Card| H["Fullscreen Monospace Terminal"]
        E -->|Tap Canvas Card| I["Agent Computer View<br/>(noVNC + Virtual Trackpad)"]
        E -->|Tap Voice Button| J["Voice Call Fullscreen Surface<br/>(Foreground Service)"]
        E -->|Tap Header Avatar| K["Bot Profile (/profile/[agentId])"]
    end

    subgraph SecondarySurfaces ["Secondary & Specialized Surfaces"]
        K --> L["Instructions Editor"]
        K --> M["Knowledge Library"]
        K --> N["Scheduled Routines (/routine/)"]
        D --> O["Box Artifacts (/box/[agentId])"]
        O --> P["Screen Captures (/screens)"]
        D --> Q["Settings Menu (/settings)"]
        Q --> R["Agent Computer VM Config"]
        Q --> S["Passkeys & Security"]
        Q --> T["Connectors Marketplace"]
    end
```
